## 🌟 Comprehensive Feature Suite

### 1. 🎙️ AI Mock Interview Simulator
- **Adaptive Question Generator**: Dynamically crafts role-specific technical and behavioral questions tailored to target job titles (Full Stack, Backend, SDE, Frontend, AI/ML) and difficulty levels.
- **Interactive Test Runner**: Clean, distraction-free test interface supporting text responses, live answer editing, and instant submission.
- **Gemini-Powered Scoring Matrix**: Generates a deep multi-dimensional scorecard evaluating technical accuracy, communication clarity, problem-solving, and confidence.
- **Historical Session Management**: Resume in-progress tests anytime with persistent storage and delete unwanted sessions.

### 2. 📄 AI Resume Analyzer & Builder
- **Instant ATS Compatibility Score**: Parses resume text and calculates algorithmic match ratings against industry standards.
- **Keyword & Skill Gap Detection**: Pinpoints missing tools, libraries, and architectural concepts for target roles.
- **Actionable Bullet Rewrites**: Suggests quantified XYZ-format bullet points powered by Gemini.
- **Live Resume Builder**: Interactive editor with responsive preview, clean section management (Education, Experience, Projects, Skills), and instant PDF download.

### 3. 🛣️ Curated LeetCode Roadmap
- **Structured Learning Track**: 45+ handpicked coding challenges across 19 critical placement topics (Arrays, Two Pointers, Sliding Window, Trees, Dynamic Programming, Graphs).
- **Personal Solution Notes**: Save personal code explanations, edge-case reminders, and time/space complexity notes per problem.
- **Live Progress Visualization**: Visual progress bars and topic completion ratios connected to Supabase Postgres.

### 4. 💻 AI Code Review Assistant
- **Automated Static Analysis**: Submit any code snippet in Python, Java, C++, or JavaScript/TypeScript.
- **Deep Code Inspections**: Detects logical bugs, security vulnerabilities, edge-case oversights, and bad practices.
- **Big-O Complexity Estimation**: Calculates time and space complexities with refactoring suggestions.

### 5. 📅 Adaptive 7-Day Study Planner
- **Dynamic Weekly Schedule**: Auto-generates personalized daily tasks focusing on weak topics detected from mock interviews and resume gaps.
- **Checklist Accountability**: Mark tasks complete day-by-day to maintain consistency leading up to placement drives.

### 6. 💼 Smart Jobs & Opportunity Portal
- **Candidate Skill Match %**: Ranks placement drives and job postings based on candidate profile skills.
- **Direct Skill Gap Analysis**: Highlights what skills you already possess vs. what you need to learn before applying.

### 7. 👥 Community Forum & Study Groups
- **Real-Time Discussions**: Channels for placement discussions, off-campus drive updates, and interview experiences via Supabase Realtime.
- **Nested Comments & Upvotes**: Engage with peers, ask doubts, and share preparation resources.
- **Collaborative Study Groups**: Create or join focused prep circles with fellow students.

### 8. 📊 Readiness Analytics & Gamification
- **Placement Readiness Index**: Holistic 0–100 readiness gauge computed across resume quality, mock interview scores, and coding completion.
- **Interactive Recharts**: Visual charts for score improvements, category breakdowns, and weekly activity.
- **Daily Streaks & Leaderboard**: Earn badges, unlock achievements, and compete on the global college leaderboard.

### 9. 🌐 Public Portfolios & Recruiter Hub
- **Shareable Portfolios (`/u/:username`)**: Showcase your verified readiness score, top skills, projects, and interview track record with custom share-cards.
- **Recruiter Search Engine**: Recruiters can filter candidates by skills, ATS range, and interview scores, and save matches to custom candidate shortlists.

## ⚙️ Local Development Setup

Follow these steps to run the complete environment on your local machine:

### 1. Prerequisites
- **Node.js** v20.x or v22.x installed ([Download Node.js](https://nodejs.org/))
- **Git** installed ([Download Git](https://git-scm.com/))

### 2. Clone Repository
```bash
git clone https://github.com/vanshika20006/Ai_Interview_Companion.git
cd "Ai_Interview_Companion"
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Configure Environment Variables
Create a local `.env` file based on `.env.example`:
```bash
cp .env.example .env
```

Ensure your `.env` contains:
```env
# Client-side visible Supabase configuration
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-supabase-anon-key
VITE_SUPABASE_PROJECT_ID=your-project-id

# Server-side Supabase configuration
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_PUBLISHABLE_KEY=your-supabase-anon-key
SUPABASE_SERVICE_ROLE_KEY=your-supabase-service-key

# AI Engine configuration (Google Gemini)
GEMINI_API_KEY=your-gemini-api-key
# Note: LOVABLE_API_KEY is supported as an alternate key
```

### 5. Start Development Server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser.

## 🚀 Deployment Guide (Vercel)

This application is optimized for deployment on **Vercel** with **TanStack Start** and **Nitro**:

1. **Push your code to GitHub:**
   ```bash
   git add .
   git commit -m "feat: complete AI placement companion implementation"
   git push origin main
   ```

2. **Connect to Vercel:**
   - Go to [Vercel Dashboard](https://vercel.com) and click **Add New > Project**.
   - Select your `Ai_Interview_Companion` repository.
   - Framework preset is automatically recognized as **TanStack Start**.
   - Node.js Version in Vercel project settings: **`22.x`**.

3. **Set Environment Variables on Vercel:**
   - Under **Project Settings > Environment Variables**, add:
     - `VITE_SUPABASE_URL`
     - `VITE_SUPABASE_PUBLISHABLE_KEY`
     - `SUPABASE_URL`
     - `SUPABASE_PUBLISHABLE_KEY`
     - `GEMINI_API_KEY`
     - `DANGEROUSLY_DEPLOY_VULNERABLE_TANSTACK_START_XSS = 1`

4. **Deploy:** Click **Deploy** to publish the production URL!
